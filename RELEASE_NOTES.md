# AI-Continuity — initial public distribution

AI-Continuity is an implemented, functioning, model-independent AI memory continuity architecture conceived, designed and directed by Kerman Haynes and maintained by AetherForge Labs, Inc.

The distribution makes the implementation and its architectural documentation available under Apache License 2.0. It connects original conversational evidence, current accepted knowledge, historical reasoning, revisions, rejected alternatives, decision histories and operational work through stable identities and source references.

The distribution includes the Python CLI, canonical schemas, validation tests and tools, starter structure, operating procedures and the executable fictional lantern continuity example. The architecture provides progressive access to current state, evolutionary history and exact original evidence across models and sessions.

Verification coverage, results and runnable checks are in [VALIDATION.md](docs/VALIDATION.md).

Developers, researchers, organizations and individuals are invited to use, test, examine, adapt and improve the work. Bug reports, adapters, interoperability improvements, documentation, tests and architectural discussions are welcome.

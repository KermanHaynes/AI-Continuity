# Start here

AI-Continuity is an implemented, functioning, tested, model-independent memory continuity architecture. Kerman Haynes is its Original Architect and Project Founder. AetherForge Labs, Inc. maintains the project under Apache License 2.0.

For setup, choose [no historical conversations](docs/ONBOARDING_NEW.md) or [existing archives](docs/ONBOARDING_HISTORY.md). The [user guide](docs/USER_GUIDE.md) explains daily operation; [QUICK_START.md](docs/QUICK_START.md) uses the actual initializer and executable demo. Ready-to-copy prompts are in [prompts](prompts/README.md).

Read [AGENTS.md](AGENTS.md) and [OPERATING_RULES.md](docs/OPERATING_RULES.md) before a memory operation. Historical reconstruction reads every scoped conversation exhaustively and preserves each artifact stage. Normal sessions and direct maintenance use progressive retrieval. Read the installed contract in this repository, verify its installation identity and activate faithful capture before working; summaries never replace SOT.

The agent handles authorized repository updates, validation and verified Git receipts. The user reviews substantive knowledge changes. The architectural contract, canonical schemas and detailed [operating procedures](docs/OPERATIONS/README.md) preserve the implemented record and transaction rules.

The default [self-contained installation](docs/INSTRUCTION_INSTALLATION.md) ensures a new model connected only to private memory can locate instructions and runtime. See the [complete reconstruction example](examples/reconstruction-lifecycle/README.md) and [running capture](docs/RUNNING_CAPTURE.md).

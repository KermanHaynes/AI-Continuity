# Operating procedures

These are the detailed procedures for an agent carrying out an authorized operation. New users can first read [Start here](../../START_HERE.md) for the vocabulary and [the user guide](../USER_GUIDE.md#normal-daily-use) for the opening-to-resumption routine. Choose a procedure below for the task you are doing; this is a reference, not a checklist to run every procedure.

Read [OPERATING_RULES.md](../OPERATING_RULES.md) for the operation-specific authority. Historical reconstruction is exhaustive; ordinary ongoing sessions are progressive. Source preservation is distinct from approved intellectual reconciliation.

| Procedure | Operation |
| --- | --- |
| [Session open](SESSION_OPEN.md) | Read current knowledge/work, expand when necessary and confirm faithful capture. |
| [Source import](SOT_IMPORT.md) | Preserve and normalize actual source evidence without automatic adoption. |
| [Subject maintenance](SUBJECT_MAINTENANCE.md) | Maintain reviewed CURRENT, EVOLUTION and exact references. |
| [Work maintenance](WORK_MAINTENANCE.md) | Preserve operational states, commitments, outcomes and resumption. |
| [Reconciliation](RECONCILIATION.md) | Apply approved intellectual and work changes with source lineage. |
| [Session close](SESSION_CLOSE.md) | Preserve faithful evidence, review changes and verify the actual receipt transaction. |
| [Audit](AUDIT.md) | Finding-only operational, structural and fidelity-preparation checks. |
| [Recovery](RECOVERY.md) | Recover verified checkpoints without replacing evidence or concurrent work. |

New users should choose [blank-history onboarding](../ONBOARDING_NEW.md) or [archive onboarding](../ONBOARDING_HISTORY.md). Full-topic reconstruction follows [HISTORICAL_RECONSTRUCTION.md](../HISTORICAL_RECONSTRUCTION.md) and [RECONSTRUCTION_ARTIFACTS.md](../RECONSTRUCTION_ARTIFACTS.md). [CONVERSATION_CAPTURE.md](../CONVERSATION_CAPTURE.md), [GIT_OPERATIONS.md](../GIT_OPERATIONS.md) and the [ready-to-copy prompts](../../prompts/README.md) support daily operation. Exact command arguments are in [SETUP.md](../SETUP.md).

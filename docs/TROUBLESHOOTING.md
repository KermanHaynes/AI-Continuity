# Resume interrupted or incomplete work

## The agent cannot access the repository

Confirm the exact private repository and authoritative branch, connection permissions and whether the environment has local Git/file tools or only read access. Do not infer native transcript access from repository access. Resume when the needed tool is available; do not invent inspected records.

## A faithful transcript is missing

Request the actual export or faithful user-assisted record selected at opening. Preserve any legitimately accessible evidence with its gaps, but do not fabricate missing text or use a summary as SOT. Do not declare complete capture until the stated scope is supported.

## Reconstruction is interrupted

Open SCOPE, COVERAGE, LINEAGE and the latest durable notes in the topic run. Verify source/transcript versions and the saved next read position. Resume the unread range or next unfinished stage. Do not repeat completed exhaustive reading because a later draft, review or session was interrupted. Changed source versions require an explicit affected-scope review, not silent reuse or total reset.

## Some historical material is unavailable

Retain the full census entry, gap and available-read status. Continue independent reading; recover the source or agree explicitly on a revised available scope. Do not call the original requested scope complete while conversations remain unexamined. Search relevance is not a recovery method or an exclusion rule.

## A draft or final was revised

Retain the original file and create a new version with parent references. Save approval evidence for a final and preserve it independently of CURRENT. If a prior draft was accidentally overwritten, recover its committed version before continuing and record the correction.

## Validation or publication fails

Keep exact findings and the last verified checkpoint. Incremental success does not replace full validation. Inspect the existing publication journal and use the documented recovery command for mechanical replay; do not overwrite concurrent edits or change original evidence to silence a finding. An unperformed external outcome remains unperformed even if a repository operation succeeds.

## A push or receipt is not verified

Retain local commits, report the precise remote limitation and retry the actual authorized push/fetch/ancestry verification when access returns. Commit and verify the receipt separately. A conversational assurance does not substitute for verified persistence.

## Two agents changed the same record

Preserve both branches/evidence, inspect the overlap and seek user judgment where authoritative meaning conflicts. Integrate unrelated work normally. Do not create duplicate identities or silently choose the newest file. See [GIT_OPERATIONS.md](GIT_OPERATIONS.md) and [RECOVERY](OPERATIONS/RECOVERY.md).

# Ready-to-copy operating prompts

New here? [Start here](../START_HERE.md) explains the record names and setup choices. For new memory, begin with prompt 1; after setup, use prompts 5 and 6 to open and close ordinary sessions. Prompts 2–4 handle existing archives; prompt 7 revises an existing position.

Fill the bracketed user-input fields with your repository, topic or request. These fields specify the operation’s inputs. The model follows the linked current operating procedures and the tools actually available in its environment.

| Prompt | Use |
| --- | --- |
| [1. Initialize](01-initialize.md) | Establish private memory and faithful capture from a blank state. |
| [2. Import archives](02-import-history.md) | Preserve and normalize authentic existing evidence without intellectual mining. |
| [3. Reconstruct a topic](03-reconstruct-topic.md) | Exhaustive reading, complete evolution and durable draft for one whole topic. |
| [4. Review and approve](04-review-narrative.md) | Retain drafts, save an approved separate final and choose CURRENT. |
| [5. Open a session](05-session-open.md) | Progressive retrieval, capture confirmation and normal work. |
| [6. Close a session](06-session-close.md) | Faithful evidence, reviewed changes and verified receipt. |
| [7. Maintain knowledge](07-maintain-knowledge.md) | Revise an established position with preserved reasoning and lineage. |

Historical reconstruction reads every scoped conversation; ordinary opening and maintenance use progressive retrieval. [OPERATING_RULES.md](../docs/OPERATING_RULES.md) makes that operation-specific precedence explicit.
